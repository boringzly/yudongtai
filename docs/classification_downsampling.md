# 分类切片两倍下采样

分类默认保持 1024×1024 的切片读取、拼接和输出网格，只把有效切片送入模型前
双线性缩小到 512×512（`align_corners=True`，与提供的示例一致）。预测得到类别编号后，
用最近邻插值恢复到原切片尺寸，再执行原有效像元掩膜、重叠区裁切和 TIFF 写出。

- 前、后时相都经过同一个分类推理入口，单图和批量模式都生效。
- 原始切片及掩膜不缩小；同时输出影像波段时也不会写入缩小后的影像。
- 变化检测算法、GF02/GF07 的整图 2 米重采样、SHP 统计与 14→6 类映射不变。
- 开启时覆盖权重或参数中的 `UPSAMPLE=True`，避免先放大两倍再缩小而抵消效果。
- 普通推理、翻转/旋转 TTA、TTACH 的模型输入均使用缩小后的切片；
  农业点分类按缩小后的行列数重组预测，再恢复原切片大小。
- TensorRT 的转换样例输入同步使用实际推理尺寸；其引擎及真实 GPU 性能需要在部署环境验证。

默认无需改工作流。可通过分类进程环境变量对比两种模式：

```text
CLIE_INFER_DOWNSAMPLE=2   默认：两倍下采样
CLIE_INFER_DOWNSAMPLE=1   关闭：保留已有输入尺度（包括原 UPSAMPLE 设置）
```

启动日志会显示原切片尺寸、模型输入尺寸、下采样倍数及 UPSAMPLE 状态。
前后时相应使用相同配置。其他环境变量值回退为默认 2。

模型输入像元数变为原来的四分之一，但 TIFF 读取/写出和 SHP 统计量基本不变，
不能保证端到端四倍加速。最近邻恢复只是恢复网格，不能恢复下采样丢失的细节；
细窄道路、小图斑可能更易丢失，应使用相同样本对照精度。最终 TIFF 沿用原流程的
工作栅格及坐标，不会因为此切片缩放而把输出 TIFF 宽高减半。

运行回归测试：`python -B -m unittest discover -s tests -p "test_*.py"`。
新增测试直接执行实际推理循环中的普通、TTA、农业分支；没有 PyTorch 的环境会
明确跳过真实张量测试，其余配置和类别恢复测试仍可运行。
